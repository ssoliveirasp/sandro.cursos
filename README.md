# sandro.cursos

Cursos de front-end publicados por Sandro Souza — material de estudo com cenário de portal corporativo bancário (módulos, ferramentas de mercado e central de erros reais por tecnologia).

🔗 **Acesse:** https://ssoliveirasp.github.io/sandro.cursos/

## Cursos disponíveis

| Curso | Tecnologia | Status | Link |
|---|---|---|---|
| Curso Angular | Angular | Publicado | [Acessar](https://ssoliveirasp.github.io/sandro.cursos/frontend/angular/) |

Novos cursos são adicionados aqui conforme forem publicados — ver o índice completo em [`index.html`](index.html).

## Estrutura

```
sandro.cursos/
├── index.html              # página inicial com a tabela de cursos
└── frontend/
    └── angular/
        └── index.html      # Curso Angular
```

Cada tecnologia publica seu curso em `frontend/<tecnologia>/`, como página autocontida (HTML/CSS/JS num único arquivo).
